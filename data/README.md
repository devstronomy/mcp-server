# Data

`planets.json` and `satellites.json` are snapshots copied from [`devstronomy/nasa-data-scraper`](https://github.com/devstronomy/nasa-data-scraper). Units are defined in `src/data.ts`, because the JSON carries none.

For sources, retrieval details, attribution and terms, see the scraper's [`data/README.md`](https://github.com/devstronomy/nasa-data-scraper/blob/master/data/README.md). Please keep those credits when you reuse the data.
